# YourWebAI
An AI-powered web app that builds responsive websites from simple user prompts.Built to make website creation faster and easier.

✨ What it does
Generates UI code using AI
Focuses on clean and responsive layouts
Outputs production-friendly frontend structure
Keeps things simple and usable instead of overcomplicated
🛠️ Tech Stack
React
Node.js
Tailwind CSS
(AI integration — depending on your setup)

📂 Project Structure
/client   → Frontend (React)
/server   → Backend (Node/Express)

Why I built this
I wanted to explore how far AI can go in actually helping with frontend development — not just giving snippets, but generating something usable.
Also, it’s a fun mix of:

UI/UX thinking
Development
AI experimentation

🚧 Current Status
Still a work in progress.
Planning to improve:
Better UI generation accuracy
More customization options
Cleaner code output
